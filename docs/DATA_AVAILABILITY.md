# Data availability

## NCBI sequence deposition

Study sequence deposition is registered under NCBI BioProject **PRJNA1522707**.
MAG assemblies and associated metadata are being deposited/linked under this
BioProject. Individual genome accessions will be added to
`data/ACCESSIONS.tsv` as they are assigned.

## Human-derived sequencing data

Raw human-containing sequencing reads are not distributed through GitHub.
This repository also does not redistribute participant-level PFAS measurements,
clinical histories or other participant-level phenotype data.

## GitHub

GitHub contains the public analysis/provenance code snapshot, current frozen
figures and release-safe derived result tables. It is not the primary archive
for nucleotide-sequence data.

The publisher-facing manuscript and supplementary package remain authoritative
for the final article version and supplementary-table numbering.
