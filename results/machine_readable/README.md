# Machine-readable source and result tables

These TSV files are the release-safe tables used to audit manuscript results and support figure reconstruction. They are retained as scientific source material rather than development outputs.

The filenames preserve the manuscript supplementary-table grouping:

- `Table_S04__*`: functional/HUMAnN and AGORA2 analyses
- `Table_S05__*`: diversity, diagnostics and exploratory effects
- `Table_S06__*`: machine-learning performance, tuning and stability
- `Table_S07__*`, `Table_S07c*`, `Table_S07d*`, `Table_S07e*`: MAG, Lindell, BacDive-AI and dereplication context

See `../../docs/FIGURES_AND_TABLES.md` for the publication mapping.
