## Derived tables

Release-safe machine-readable derived result tables are under
`results/machine_readable/`.

Journal supplementary Excel workbooks are deliberately not duplicated in this
GitHub release because the publisher package is authoritative and some
workbooks contain row-level study data not required for public code
reproducibility.
