# Public data and accessions

Large nucleotide-sequence datasets are not stored in GitHub.

The study is registered under NCBI BioProject **PRJNA1522707**. MAG assemblies
and associated metadata are being deposited/linked under that BioProject;
individual accessions will be added to `ACCESSIONS.tsv` when assigned.

Raw human-containing sequencing reads and participant-level PFAS/clinical data
are not redistributed in this repository.
